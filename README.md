## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` is standard library only, draws the image with no network, and
writes a deterministic 1024x1024 PNG to `entry.png` in the output
directory (`/output/entry.png` in the grader). It never reads any file,
never touches the working directory, and verifies its own write by
reading the file back.
